## Required Information for Every Prompt

1. Prompt ID
2. Feature name
3. Objective
4. AI tool used
5. Original prompt
6. Expected output
7. Actual result
8. Files changed
9. Testing result
10. Final status

## Development Rules

- Save every important coding prompt.
- Do not overwrite previous prompt versions.
- Record important prompt modifications.
- Review AI-generated code before accepting it.
- Run relevant tests before marking a task complete.
- Never include API keys, passwords or private credentials.
- Keep prompts synchronized with actual project requirements.

## Status Definitions

- PLANNED — Not started.
- IN PROGRESS — Currently developing.
- PASSED — Implementation and tests successful.
- FAILED — Tests or implementation unsuccessful.
- NEEDS REVIEW — Requires manual verification.

## Golden Rule

**Every important AI-generated change must be traceable to its prompt, code changes and test results.**
